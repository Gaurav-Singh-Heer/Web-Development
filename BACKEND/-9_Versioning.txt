All Symbol Summary:-

1. version: The version must match exactly (e.g., `4.18.2`).
2. >version: The version must be strictly greater than the specified version (e.g., `>4.18.2`).
3. >=version: The version must be greater than or equal to the specified version (e.g., `>=4.18.2`).
4. <version: The version must be strictly less than the specified version (e.g., `<4.18.2`).
5. <=version: The version must be less than or equal to the specified version (e.g., `<=4.18.2`).
6. ~version: "Approximately equivalent to" the specified version, allowing patch-level updates but 
|            not minor version updates (e.g., `~4.18.2` would allow updates up to `4.19.0` but not  
|            `4.20.0`).
7. ^version: "Compatible with" the specified version, allowing updates to the minor and patch 
|             versions within the same major version range (e.g., `^4.18.2` allows updates to 
|             `4.x.x` but not `5.x.x`).
8. version1 - version2: Equivalent to specifying a version range from `>=version1` to `<=version2` 
|                      (e.g., `4.18.2 - 4.19.0` is the same as `>=4.18.2 <=4.19.0`).
9. "Latest"- installs the most recent version available, including major version changes, 
|            potentially causing breaking changes.
