AUTHORIZATION

Till now we saw Authentication

--> Difference between Authentication and Authorisation:-
    - Authentication means to authenticate a user or to make him login means I know this user belongs to my this particular application
    - Authorisation means to check for particular resource that are u authorised to access  that

--> Authentication
    - Verifies the identity of a user or service. This is usually the first step in the cybersecurity process. 
    | The user must provide physical or nonphysical evidence to confirm their identity. 

--> Authorization
    - Determines what resources a user can access. This process is usually coupled with authentication so that 
    | the server has some concept of who the client is.

--> REAL LIFE EXAMPLE

    - Authentication is the process of verifying who someone is. It's like showing your ID to prove you are who 
    | you say you are.
    - Authorization is the process of determining what someone is allowed to do. It's like being granted 
    | permission to enter a specific room or access certain files.

    - EXAMPLE:
    |   Imagine a company where employees use a computer system to access their work files.
    |    * Authentication: When an employee wants to log in, they enter their username and password. This is the 
    |      authentication step. The system verifies that the username and password match, confirming the  
    |      employee's identity.
    |    * Authorization: Once authenticated, the system determines what the employee is allowed to access based 
    |      on their role. For example:
    |      * A back-end employee might be authorized to view and edit customer data but not change pricing.
    |      * A manager might have authorization to view all employee data, change pricing, and approve employee 
    |      requests.

    In Short:
    * Authentication answers the question: "Are you who you say you are?"
    * Authorization answers the question: "What are you allowed to do?"

IN Middlewares/auth.js

    function checkForAuthentication(req, res, next) {
        const authorizationHeaderValue = req.headers['authorization'];
        req.user=null;
        if(!authorizationHeaderValue || !authorizationHeaderValue.startswith('Bearer')){
            return next();
        }
        
        const token = authorizationHeaderValue.split('Bearer ')[1];
        const user = getUser(token)

        req.user = user;
        return next();
    }   

    WORKING:- Here we are taking authorizationHeaderValue Checking it we put it in req.user and then 
    |         call next function

Another Function To Check Role of a person for Authorization:-

function restrictTo(roles) {    // Here we will pass array of Roles // Role example:- Admin, Employee, Normal, Customer
    return function(req,res,next){
        if(!req.user) return res.redirect("/login");

        if(!roles.includes(req.user.role)) return res.end("UnAuthorized");

        return next();   // when both if Satisfied
    }
}
