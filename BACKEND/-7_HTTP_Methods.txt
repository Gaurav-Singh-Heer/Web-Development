HTTP GET        

By default our browser do GET data

When you want to get some data from the server

When our server gets GET Request then our server goes to database and reads the data and whatever
data comes from the database is sent to the client.

Means whenever i will do HTTP GET request on our server then our expectation is to get some data.

Example:- When u open ur browser and when u enter any url after putting it in the browser ,
          when u press enter then browser always creates get request to our server by default.


To Check it:-

Go to any browser Youtube or Leetcode

Search any vedio or questions

then after opening it 

1)-> Do right click
2)-> Inspect
3)-> Network
4)-> Refresh Site
5)-> click on description

HTTP POST

When you want to send and mutate some data in server

Send data means , Like when u open any social media website then there we have a form for sign in 
|                or sign up or any feedback form. At these form we type our data and send to the 
|                server. 
|                So, when we want to send our data at a server and we expect that this data will
|                be entered at the database

Mutation means, To change data or add data. 

So, when you want to send and mutate some data in the server the we do POST request.

Let's say we have a social media website and user will sign up over there. His data(Phone no, 
mail,password) will be sent to the server using POST request because by this post request we 
will understand that we have to create something.

So, in the database we will set query to create user at the database, This is it's username and 
this is password.

Whenever we submit our data at the forms(HTML Form) they create a post request

Let's say we have a form with:-

Email,Phone,Password
CREATE ACCOUNT

when we will at our data and then click on CREATE ACCOUNT. Then this will create a post request
and in it's body it will send {Form Data} along.

Our server will see that this is post Request
