MongoDB is a DataBase. It's Code has JvaScript Like Syntax

MongoDB:-
    - No-SQL Document Based DataBase                   // No-SQL work on Document // SQL work on Table
    - Strong Support for Aggregation Pipes
    - Works on BSON format
    - Best for Node Applications

-----------------------------------------------------------------------------------------------------------------

MongoDB Architecture:-
    - In MongoDB we have Collections . As in SQL we have Table. Similarly in MongoDB we have Collections
    - So, In Broader level we have collections.
    - Let say we have Collection 'users'. And in Collection we have entry called Document-1,Document-2. We can have thousands or Lakhs of Document inside a collection

-----------------------------------------------------------------------------------------------------------------

To Interact In MongoDB Commands:-

    1. show dbs:         Displays all databases currently available in the MongoDB server.  
    2. use <db_name>:    Switches to the specified database or creates it implicitly.  
    3. show collections: Lists all collections within the currently selected database.  
    4. db.coll.find():   Retrieves and displays documents from the specified collection.  
    5. db.coll.insert(): Adds a new document to the specified collection in MongoDB.
