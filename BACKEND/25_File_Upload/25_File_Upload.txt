As we had seen many times while uploading some file while filling forms. How is that done

--> To Upload a file we have to use a Library Known as Multer(https://www.npmjs.com/package/multer)
|
|   - multer is a Library which gets easily plugin with express
|   - Multer package/Libary helps us with File Upload 
|
|   - At homepage.ejs we have to add 3 properties action, method, enctype
|
|    <form action="/upload" method="POST" enctype="multipart/form-data" >
|        <input type="file" name="profileImage">
|        <button>Upload</button>
|    </form>
|
|   - action means, at which url we have to Upload this
|   - enctype means, as we are sending a file in this so we have to add this encryption Type to it. Without this we 
|                  will not be able to upload this file.
|
|   - now at index.js we have to make this post route of "/upload"      (app.post("/upload", (req,res) => {});)
|   - and as we are uploading form data so we have to use (express.urlencoded) as learned earlier urlencoded helps 
|     us to parse our form-data    (app.use(express.urlencoded({extended:false}))). Used this bcoz data coming from 
|     frontend is not JSON it is a form data and to parse it we have to use (express.urlencoded)

--------------------------------------------------------------------------------------------------------------------

|   +-------------------------------------+----------------------------------------------+
|   |           express.urlencoded()      |         Middleware for parsing data          |
|   |-------------------------------------|----------------------------------------------|
|   | Parses URL-encoded data in the body | Used when forms are submitted via POST       |
|   | of incoming HTTP requests.          | or when URL-encoded data is sent in requests.|
|   +-------------------------------------+----------------------------------------------+
|   
|   +-------------------------------------+-----------------------------------------------+
|   |               extended              |          Option to determine parsing type     |
|   |-------------------------------------|-----------------------------------------------|
|   | If `false` (default)                | Uses the `querystring` library to parse simple|
|   | - Parses simple key-value pairs      | key-value pairs (e.g., `key=value`).         |
|   |   (e.g., `key=value`)               |                                               |
|   | - Cannot handle nested objects      |                                               |
|   +-------------------------------------+-----------------------------------------------+
|   
|   +-------------------------------------+------------------------------------------------+
|   |          extended: true             |    Option to allow complex parsing             |
|   |-------------------------------------|------------------------------------------------|
|   | If `true`                           | Uses the `qs` library to parse data with       |
|   | - Allows handling of nested objects | complex structures (e.g., `key[subkey]=value`).|
|   |   (e.g., `key[subkey]=value`)       |                                                |
|   | - Useful when dealing with deeply   |                                                |
|   |   nested or array-like data         |                                                |
|   +-------------------------------------+------------------------------------------------+
|   
|   Example with `extended: false`:
|   Form data submitted via POST:
|   +-----------------------+
|   |    Key    |  Value    |
|   |-----------|-----------|
|   |   name    |   John    |
|   |   age     |   30      |
|   +-----------------------+
|   Parsed Data (as Object):
|   +-----------------------------------------------+
|   |       { name: 'John', age: '30' }             |
|   +-----------------------------------------------+
|   
|   Example with `extended: true`:
|   Form data submitted via POST (with nested data):
|   +----------------------------------+
|   |    Key            |  Value       |
|   |-------------------|--------------|
|   | user[name]        | John         |
|   | user[age]         | 30           |
|   +----------------------------------+
|   Parsed Data (as Object):
|   +----------------------------------------------------+
|   |     { user: { name: 'John', age: '30' } }          |
|   +----------------------------------------------------+

Now at "/upload"  (app.post("/upload", (req,res) => {});)

|   - we can handle our files in 2 ways :- 
|   1) - simply import multer  (const multer = require("multer");)
|      - then we have to create and instance of upload  (const upload = multer({dest:"uploads/"});) this means , 
|        whatever data user will upload directly upload that in uploads Folder. Here upload is basically a 
|        Middleware
|      - Now, what we want is (app.post("/upload", (req,res) => {});) for this "/upload" particular route whenever 
|        we get a request we upload a single file named profileImage(at homepage.ejs [<input type="file" name="profileImage">]) 
|
|        So, now  post request is updated as:-
|
|           app.post("/upload", upload.single("profileImage"), (req,res) => {
|               console.log(req.body);
|               console.log(req.file);
|           
|               return res.redirect("/");
|           });
|

Now method to read the uploaded Files:- in the same link bottom (https://www.npmjs.com/package/multer) we have, DiskStorage which gives us full control how to save our File

|           DiskStorage
|           The disk storage engine gives you full control on storing files to disk.
|           
|           const storage = multer.diskStorage({
|             destination: function (req, file, cb) {
|               cb(null, '/tmp/my-uploads')
|             },
|             filename: function (req, file, cb) {
|               const uniqueSuffix = Date.now() + '-' + Math.round(Math.random() * 1E9)
|               cb(null, file.fieldname + '-' + uniqueSuffix)
|             }
|           })
|           
|           const upload = multer({ storage: storage })

---> NOW , in 2_index_DiskStorage.js we don't want (const upload = multer({dest:"uploads/"});) 

|       Here, we have 
|       const storage =  multer.diskStorage({             // in this we have 2 parameters
|           destination: function (req, file, cb) {       // 1-> destination  (callback Function) // 1-> destination  (callback Function) , here we tell where or inside which folder our file is to be stored (file, is file uploaded by user; cb is the callback function ) 
|               return cb(null, "./uploads");              // null means no error
|             },
|             filename: function (req, file, cb) {        // 2-> Filename , here we can take original file name but in that the problem is if another user uploaded with same name then it would be overwrite. So, here we will generate our own filename
|               return cb(null, `${Date.now()}-${file.originalname}`); // created our own filename(date+filename(in Local system)) ${Date.now()}-${file.originalname}
|             }
|       });
|       
|       // const upload = multer({storage: storage}); // OR
|       const upload = multer({storage});
