On 20, we talked about Statefull Authentication in Which our server had a state and we have to maintain 
it on our backend 

There PROBLEM WAS:-

1->If our server is restarted or our state is lost then all user get Log out
2->Statefull Authentication is memory intensive means it uses our server's memory. And we had limited   
   memory over our server


To Solve these Problems we have Stateless Authentication

------------------------------------------------------------------------------------------------------

STATELESS

Means we don't have any state on our backend.

If we don't have state then how do we keep trak of our data OR maintain our state.

STATELESS in Node.JS 

1--> Remove State, 
2--> Make user token/id.
3--> Data of user is kept inside token/id and will be locked.(locked so that it can be read by any but cannot be changed by any)

For This we use JWT tokens or JSON WEB TOKENS (https://jwt.io/)
