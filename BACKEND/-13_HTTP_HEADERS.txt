Let's say,

Person A sends a Mail to person B. Content of letter is inside envelope and at outside we have extra Info(From, TO, Weight).

So, Similarly:-

Person A   = Client
Person B   = Server
Mail       = Request
Letter     = Data
Extra info = HTTP HEADERS

Headers in real world look like ,

    From:- is an ip address (192.168.1.1)
    To  :- is an ip address (10.1.1.2)
    Content Type :- JSON

-----------------------------------------------------------------------------------------------------------------

In Mail we have address of From and To.

Similarly,

When one computer send information to another then we have IP of Boths

HEADERS,
    - HTTP Headers are an important part of the API request and response as they represent the meta-data
    (meta-data is data about data) associated with the API request and response.

    - Headers carry information for The request and Response Body. 
 
Q- What are Headers in HTTP?
A- An HTTP header is a field of an HTTP request or response that passes additional context and metadata
   about the request or response.
