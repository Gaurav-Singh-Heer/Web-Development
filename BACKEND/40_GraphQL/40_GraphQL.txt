GraphQL (https://graphql.org/)

|    So, to solve the REST_API's Problem GraphQL is used.

Why we use GraphQL?
GraphQL addresses a common problem with REST APIs: over-fetching data. When retrieving information from a 
REST API, you often receive more data than needed.

GraphQL Advantages: 
|          - Data Efficiency:  GraphQL allows clients to request specific data, preventing the server from sending
|                              unnecessary information. This leads to faster loading times, especially crucial when 
|                              dealing with large datasets.
|          - Prevents Over-fetching: Clients receive only the requested data, leading to faster load times.
|          - Optimized Performance: Eliminates multiple API calls by allowing clients to fetch related data in a single query.

FrontEnd with HTML

--> At client folder Created index.html

|       CODE:-
|                   <!DOCTYPE html>
|                   <html lang="en">
|                   <head>
|                       <meta charset="UTF-8">
|                       <meta name="viewport" content="width=device-width, initial-scale=1.0">
|                       <title>GraphQL Client</title>
|                   </head>
|                   <body>
|                   
|                       <h2>GraphQL Client</h2>
|                   
|                       <button onclick="fetchTodos()">Fetch Todos</button>
|                       <button onclick="fetchUsers()">Fetch Users</button>
|                       
|                       <div>
|                           <input type="text" id="userId" placeholder="Enter User ID">
|                           <button onclick="fetchUserById()">Get User</button>
|                       </div>
|                   
|                       <div id="result">Results will be displayed here...</div>
|                   
|                       <script>
|                           const API_URL = "http://localhost:8000/graphql";
|                   
|                           async function fetchTodos() {
|                               const query = `{
|                                   getTodos {
|                                       id
|                                       title
|                                       completed
|                                   }
|                               }`;
|                               fetchGraphQL(query);
|                           }
|                   
|                           async function fetchUsers() {
|                               const query = `{
|                                   getAllUsers {
|                                       id
|                                       name
|                                       email
|                                   }
|                               }`;
|                               fetchGraphQL(query);
|                           }
|                   
|                           async function fetchUserById() {
|                               const userId = document.getElementById("userId").value;
|                               if (!userId) {
|                                   alert("Please enter a User ID");
|                                   return;
|                               }
|                               const query = `{
|                                   getUser(id: "${userId}") {
|                                       id
|                                       name
|                                       email
|                                       phone
|                                   }
|                               }`;
|                               fetchGraphQL(query);
|                           }
|                   
|                           async function fetchGraphQL(query) {
|                               const response = await fetch(API_URL, {
|                                   method: "POST",
|                                   headers: { "Content-Type": "application/json" },
|                                   body: JSON.stringify({ query })
|                               });
|                   
|                               const result = await response.json();
|                               document.getElementById("result").innerText = JSON.stringify(result, null, 2);
|                           }
|                       </script>
|                   
|                   </body>
|                   </html>

|       --> Buttons

|               "Fetch Todos" → Fetches all todos from the GraphQL API.

|       
|       -->Input Field
|       
|               Enter a User ID to fetch their details.
|       
|       -->Results Section
|       
|               Displays the response from the GraphQL API in JSON format.

|    How to Run:
