-------------------------------------------------------------------------------------------------
URL-> Uniform Resource Locator

Example-> https://www.piyushgarg.dev/

Here, 
    1) https:-
      -Protocol:Hypertext Transfer Protocol Secure

        Protocol means how to communicate with the server. Protocol is a set of rules that tells
        browser how to communicate.
        Like in https -> All request and response are encrypted. It is SSL certified 
                http -> No SSL certificate and also less secure 

    2) www.piyushgarg.dev (Domain):-
        -Domain:User Friendly Name of IP Address of My server

        there is an IP address of a server but obviously we can't learn it. So, we purchase a 
        domain to point to that IP. This domain becomes the user Friendly Name of the site.

    3) /:-
        - Path: Homepage or Root Path

        Example :- www.piyushgarg.dev/about
|                  www.piyushgarg.dev/contact-us 

        - Nested Path:

        Example :- www.piyushgarg.dev/project/1
|                  www.piyushgarg.dev/project/2

    4) (userId=1&a=2) Query Parameters:

        Example:- piyushgarg.dev/about?userId=1&a=2

        They are basically the extra information which we pass along with our URL

const http=require("http")
const fs=require("fs")

const myServer=http.createServer((req,res)=>{
    
    if(req.url==="/favicon.ico") return res.end(); // By this we will not log /favicon.ico in txt file
    const log=`${Date.now()}:${req.url} New Request Received\n`;
    fs.appendFile('6_2_log.txt',log,(err,data)=>{
        switch(req.url){
            case '/':
                res.end("HomePage");
            break
            case '/about':
                res.end("I am Gaurav Singh Heer");
            break
            default:
                res.end("404 Not found");
            break
        }
    }); // not using synchronous as if all thread in work user has to wait
})

myServer.listen(8000,()=>console.log("Server Started!"));
