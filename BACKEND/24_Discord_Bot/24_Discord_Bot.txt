    ->Paste URL at NEXT tab

----------------------------------------------------------------------------------------------------------------

GatewayIntentBits :- Means types of permission we are giving
(https://discordjs.guide/popular-topics/intents.html#privileged-intents)

--> `GatewayIntentBits.Guilds` allows the bot to access and respond to server-related events, such as joining 
|    servers or managing channels.

--> `GatewayIntentBits.GuildMessages` allows the bot to receive and process messages sent within guild (server)
|    text channels, excluding direct messages.

--> `GatewayIntentBits.MessageContent` to access the content of message we wrote

Made commands.js By using Content From(https://discord.js.org/docs/packages/discord.js/14.17.3):

|   import { REST, Routes } from 'discord.js';
|   
|   const commands = [
|     {
|       name: 'ping',
|       description: 'Replies with Pong!',
|     },
|   ];
|   
|   const rest = new REST({ version: '10' }).setToken(TOKEN);
|   
|   try {
|     console.log('Started refreshing application (/) commands.');
|   
|     await rest.put(Routes.applicationCommands(CLIENT_ID), { body: commands });
|   
|     console.log('Successfully reloaded application (/) commands.');
|   } catch (error) {
|     console.error(error);
|   }
