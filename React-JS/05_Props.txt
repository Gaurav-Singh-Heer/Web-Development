Props:- Props are like parameteres of a function

In Todoie App at 04_to_do_app
We had output as ,
![Design](04_to_do_app/Output_Design.jpg)

In this eat task was repeating Blindly as we wrote in Code 

We, Don't have a Way to control this it is just rendering what we had said 

To Control this problem we have Props

Till now we had used function without focusing at the Parameter. Now will add parameter's at function to make it generic which is called as Props.


Function Without Parameter:

|               function MyHeader(){
|                   return <h1>Hello World</h1>
|               }

Function With Parameter: Prop

|               function MyHeader(props){
|                   return <h1>{props.title}</h1>
|               }
|               
|               <Myheader title="This is my Heading"/>

**We can Also pass More than one Attribute at App.jsx**

Conditionally Rendering at components/TodoItem.jsx to not show the task which are completed:-

|                       {props.completed ? <></> : <input type="checkbox" />}
|                       <span className="todo-item-text">{props.text}</span>
|

Here, props.completed is a boolean value either True or False
if task completed render nothing else render checkbox

Now passing Code as Completed at App.jsx:-

|      <TodoItem completed={true} text="Code"/>
