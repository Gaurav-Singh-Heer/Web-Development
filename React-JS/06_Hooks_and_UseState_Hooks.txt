--> Use-State Hook 

What is a State?
A state of a component is a variable that holds some information that may change over the lifetime of the component.
Whenever the value of the state changes, the component re-renders itself with updated values.

Every Component has it's own state

Use-State Hook code:-

import React, {useState} from 'react';

function CounterComponent(){
    const [count, setCount] = useState(0);         // 0 is initial value of count   // At, [count, setCount] here at 0th index we have count (variable) and at index 1 we have function with which we can update the value of count

    return(
        <div>
            <p> Count is {count} </p>
            <button onClick = {()=> setCount(count+1)}>Increment</button>
        </div>
    )
}

Whenever we will tap at Increment button count will increase.

How we will get to know what is a Hook ?
All the Hooks in React Starts with the "use" example useState,useCallback,useMemo..etc

Good Practise :- Use "set" in the prefix of the function of the Hook example:- [count, setCount] here we do setCount with prefix "set". As this makes it more clear that setCount will set the value of the count variable.
