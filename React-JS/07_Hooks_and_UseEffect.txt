# React Hooks and useEffect Hook

## Life Cycle of a React Component

```
    ----------> Constructed ----------
    |                                |
    |                                V
 Un-Mounted                       Mounted
    ^                                |
    |                                |
    ---------- Constructed <---------
                    OR
                  Update
```

UseEffect Hook is For eg we need to run a piece of code(function(){}) between this lifecycle when the function will be mounted on the screen 

For example we have a Card of Blog Page. So when we will mount Page on screen we will call a function which will fetch content of Blog and display them

UseEffect Hook :- Run code during the change in lifecycle of a component

--> It's Code is as:-

import React, {useEffect} from 'react';

const MyComponent(){
    
    useEffect(() =>{
        console,log('Hello');
    },[])

    return (
        <div>
            <p> Hey There </p>
        </div>
    )
}

useEffect(() =>{console,log('Hello')},[])         

Here First Argument:- {console,log('Hello')} is function that runs when state changes
     Second Argument:- [] is a Dependency Array.

Now we want that UseEffect must run then also when our state is being updated

So, Now will Create new UseEffect at /components/My_Component_2

|                       import React, {useEffect, useState} from "react";
|                       
|                       const MyComponent = () => {
|                       
|                           const [count, setCount] = useState(0);    
|                       
|                           useEffect (()=>{
|                               console.log('My Component is Mounting')
|                           }, [])
|                       
|                           useEffect (()=>{
|                               console.log("Count got updated", count)
|                           }, [count]);                         // Now when count update this function will run  // Dependency Array means when to run this Component
|                       
|                           return (
|                               <div>
|                                   <p>Count is {count}</p>
|                                   <button onClick={()=> setCount(count+1)}>Increment</button>
|                                   <button onClick={()=> setCount(count-1)}>Decrement</button>
|                               </div>
|                           )
|                       }
|                       
|                       export default MyComponent

|                   }

Output:- Here we Increment value of Count_2 from 40 to 44 but not displaying it as we hadn't added it on dependency Array

![Before Adding Count_2 at Dependecy Array..](./07_Hooks_and_UseEffect_Hook/screenshots/5.jpg)


After adding count_2 in Dependency Array

|               useEffect (()=>{
|                   console.log("Count got updated", count)
|                   console.log("Count_2 got updated", count_2)
|               }, [count,count_2]);                         // Now when count update this function will run  // Dependency Array means when to run this Component
|           

Output:- Here we Decrement value of Count_2 from 40 to 39 and it is displayed at console as we added it on dependency Array

![After Adding Count_2 at Dependecy Array..](./07_Hooks_and_UseEffect_Hook/screenshots/6.jpg)


SUMMARY:-

1) When Dependency Array is Empty :- It Runs when component is Mounted 
2) Added Variable at Dependecy Array :- It Runs when component is Updated
