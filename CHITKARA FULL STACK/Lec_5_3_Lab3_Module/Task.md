Lab 3 Activities

Problem Statement: Book Management System Using Node.js Modules

Create a Node.js CLI application to manage a small book library The app must be modular, with separate files for logic like adding, Isting, and searching books.

The student should demonstrate a clear understanding of module exports and require.

Functional Requirements

1. Add a Book

2. Accept book details: title, author, and 158N.

3. Store them in an in-memory array.

4. List All Books

5. Display all books in tabular format.

6. Search Book by Title

7. Enter a title or keyword and display

matching books



STRUCTURE:-

book-app/

book.js, Defines Book model as a class or object

operations.js, Contains functions: addBook(), listBooks(), searchBook

App.js, Main file to call operations using require
