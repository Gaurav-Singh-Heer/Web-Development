|  Aspect            | Before (Using Custom CSS)                       | After (Using Tailwind CSS)
|  ------------------|-------------------------------------------------|-------------------------------------------------------
|  HTML Structure    | <div class="container">                         | <div class="bg-black text-white">
|  CSS Styling       | Written in a <style> tag inside the <head>.     | Inline utility classes provided by Tailwind (e.g., bg-black, text-white).
|  Code Reusability  | Requires defining a CSS class (.container)      | Directly uses Tailwind's utility classes for faster and reusable styling.
|  CSS Load Time     | Custom styles written manually, increasing the  | Optimized, pre-built CSS classes from Tailwind, reducing CSS bloat.
|                    | need for additional CSS definitions.            | 
|  Ease of Use       | Developers need to write and manage custom      | Utility-first framework simplifies the process with pre-designed classes.
|                    | classes manually.                               | 
|  Responsive Design | Requires writing additional CSS media queries   | Tailwind provides built-in responsive classes (e.g., md:bg-red-500, lg:text-xl) for responsiveness.
|                    | manually.                                       | 
|  Output Code       | <div class="container">Hey Gaurav</div>         | <div class="bg-black text-white">Hey Gaurav</div>

TAILWIND CSS Using CLI:- (https://tailwindcss.com/docs/installation/tailwind-cli)

|           Step 1: - npm init -y
|           Step 2: - npm i -D tailwindcss
|           Step 3: - npm install tailwindcss @tailwindcss/cli
|           Step 4: - npx tailwindcss init
|           Step 5: - mkdir src
|           Step 6: - At src make input.css
|                                           @import "tailwindcss";
|           Step 7: - npx tailwindcss -i ./src/input.css -o ./src/output.css --watch
|                   This command scans your input.css file for Tailwind directives and generates the output CSS file (output.css).
|                   The --watch flag ensures that the build process automatically rebuilds whenever you save changes to your files.

| As, npx tailwindcss -i ./src/input.css -o ./src/output.css --watch command is very long so write it in scripts of 
| package.json
|                           "scripts": {
|                              "test": "echo \"Error: no test specified\" && exit 1",
|                              "build": "npx tailwindcss -i ./src/input.css -o ./src/output.css --watch"
|                            },
|
| Now just do  :- npm run build                                   , On Terminal

CAN MAKE RESPONSIVE USING BREAKPOINTS (https://tailwindcss.com/docs/responsive-design#using-custom-breakpoints)

    +----------------+--------------------+-----------------------------------------------+
    | Breakpoint     | Minimum Width      | CSS                                           |
    +----------------+--------------------+-----------------------------------------------+
    | sm             | 40rem (640px)      | @media (width >= 40rem) { ... }               |
    | md             | 48rem (768px)      | @media (width >= 48rem) { ... }               |
    | lg             | 64rem (1024px)     | @media (width >= 64rem) { ... }               |
    | xl             | 80rem (1280px)     | @media (width >= 80rem) { ... }               |
    | 2xl            | 96rem (1536px)     | @media (width >= 96rem) { ... }               |
